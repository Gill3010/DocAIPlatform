# JATS 1.3 Schema

Para validación, usar el XSD oficial:

```
xmllint --schema https://jats.nlm.nih.gov/publishing/1.3/xsd/JATS-journalpublishing1-3.xsd output.xml
```

O descargar los XSD desde: https://public.nlm.nih.gov/projects/jats/publishing/1.3/xsd/
y colocarlos en este directorio si se requiere validación offline.
