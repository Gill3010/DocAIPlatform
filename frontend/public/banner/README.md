# Imágenes del cintillo

Coloca aquí tus 4 imágenes para el carrusel del dashboard:

- `valor-1.png` – Validación y precisión (XML, schema compliant)
- `valor-2.png` – IA para múltiples formatos (PDF, DOCX, XML...)
- `valor-3.png` – Procesamiento académico con IA
- `valor-4.png` – Dashboard y métricas

**Recomendaciones:**
- Formato: PNG, JPG o WebP
- Resolución sugerida: 1200×400 px o 1600×450 px
- El texto se superpone con overlay oscuro; evita zonas muy claras en el centro

Si no añades imágenes, el cintillo usará gradientes de la paleta DocAI.
